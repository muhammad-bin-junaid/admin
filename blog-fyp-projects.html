Top 5 Projects for Your FYP (Final Year Project)

Published: Sep 2026

Introduction

Choosing an FYP that balances academic rigor with realistic component procurement budgets is the biggest challenge for Pakistani engineering students. The projects below are designed to score high marks while using components you can actually source locally without overseas shipping delays or exorbitant costs.

Project 1: Smart Grid & IoT Energy Monitoring System

Focus: Addressing local power distribution and load monitoring

Core Tech:

ACS712 Current Sensor ZMPT101B Voltage Module ESP32

This project monitors real-time energy consumption at the household level, pushing data to an IoT dashboard. It's directly relevant to Pakistan's power distribution challenges and load-shedding monitoring.

Project 2: Autonomous Agricultural Soil Health Analyzer

Focus: Smart farming applications for regional agriculture

Core Tech:

NPK Soil Sensor Moisture Sensor OLED Display LoRa/GSM Module

Designed for Pakistan's agricultural backbone, this system analyzes soil nutrient levels (Nitrogen, Phosphorus, Potassium) and moisture content, transmitting data wirelessly to farmer dashboards via LoRa or GSM networks.

Project 3: Remote Patient Vital Signs Telemetry System

Focus: Low-cost healthcare telemetry for rural clinics

Core Tech:

MAX30102 Pulse Oximeter AD8232 ECG Sensor MQTT Cloud Dashboard

This system tracks heart rate, SpO2, and ECG data in real-time, transmitting to a cloud dashboard via MQTT. It's built for remote rural clinics where specialist doctors aren't physically present.

Project 4: OpenCV Computer Vision Automated Conveyor Belt

Focus: Industrial quality control and material handling automation

Core Tech:

Python/OpenCV Camera Arduino Motor Driver Servo Sorting Arms

A vision-guided conveyor belt system that uses OpenCV for object detection and classification, triggering servo-based sorting arms to separate items by color, shape, or defect — ideal for textile and manufacturing industries.

Project 5: Municipal Water Quality & Flow Management Node

Focus: Automated urban utility monitoring

Core Tech:

pH Sensor Turbidity Sensor YF-S201 Flow Meter ESP8266

This node monitors municipal water quality parameters including pH, turbidity, and flow rate in real-time. Data is uploaded to a cloud dashboard for automated alerts on contamination or leaks — directly applicable to Karachi's water supply challenges.
