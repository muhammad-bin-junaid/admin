Ultrasonic Distance Meter

Category Sensors & Display Instrumentation Difficulty Beginner Time 1.5 Hours Cost Rs. 850 PKR

◆ Overview

This project measures physical distance to an obstacle using high-frequency ultrasonic sound pulses (40 kHz). The system calculates the time-of-flight between signal transmission and echo reception, converting duration into centimeters displayed in real time on an I2C-enabled 16x2 LCD screen with an audio alert.

◆ Calculation Formula

Distance (cm) = (Echo Duration in microseconds × 0.0343) / 2

Distance = (duration × 0.0343) / 2

Sound travels at ~343 m/s (0.0343 cm/µs). Divide by 2 because the pulse travels to the obstacle and back.

◆ Core Control Code (C++)

Arduino Sketch · C++ 
#include <Wire.h>
#include <LiquidCrystal_I2C.h>

LiquidCrystal_I2C lcd(0x27, 16, 2);
const int trigPin = 9;
const int echoPin = 10;
const int buzzerPin = 11;

void setup() {
  pinMode(trigPin, OUTPUT);
  pinMode(echoPin, INPUT);
  pinMode(buzzerPin, OUTPUT);
  lcd.init();
  lcd.backlight();
}

void loop() {
  digitalWrite(trigPin, LOW);
  delayMicroseconds(2);
  digitalWrite(trigPin, HIGH);
  delayMicroseconds(10);
  digitalWrite(trigPin, LOW);

  long duration = pulseIn(echoPin, HIGH);
  float distance = duration * 0.0343 / 2;

  lcd.setCursor(0, 0);
  lcd.print("Distance Metric:");
  lcd.setCursor(0, 1);
  lcd.print(distance);
  lcd.print(" cm    ");

  if (distance > 0 && distance < 10) {
    digitalWrite(buzzerPin, HIGH);
  } else {
    digitalWrite(buzzerPin, LOW);
  }
  delay(100);
}

◆ Troubleshooting & Assembly Tips

  • ! If LCD lights up but shows no text, turn the blue potentiometer on the back of the I2C module to adjust display contrast.
  • ! Ensure I2C address is correctly set to 0x27 or 0x3F in code depending on your PCF8574 chip variant.
