Line Following Robot

Category: Robotics / Autonomous Navigation Difficulty: Beginner Time: 3 Hours Cost: Rs. 1,850 PKR

Overview

The Line Following Robot autonomously detects and tracks a high-contrast path (black electrical tape on a light surface). Dual IR reflectance sensors mounted beneath the front chassis continuously poll surface contrast values, allowing an onboard Arduino Nano to drive a dual H-bridge motor controller dynamically.

Core Control Code (C++)

Arduino Sketch C++ 
const int leftIR = 2;
const int rightIR = 3;
const int ENA = 5, IN1 = 6, IN2 = 7;
const int IN3 = 8, IN4 = 9, ENB = 10;

void setup() {
  pinMode(leftIR, INPUT);
  pinMode(rightIR, INPUT);
  pinMode(ENA, OUTPUT); pinMode(IN1, OUTPUT); pinMode(IN2, OUTPUT);
  pinMode(ENB, OUTPUT); pinMode(IN3, OUTPUT); pinMode(IN4, OUTPUT);
}

void loop() {
  bool leftState = digitalRead(leftIR);
  bool rightState = digitalRead(rightIR);

  if (!leftState && !rightState) { moveForward(); }
  else if (leftState && !rightState) { turnLeft(); }
  else if (!leftState && rightState) { turnRight(); }
  else { stopMotors(); }
}

void moveForward() {
  analogWrite(ENA, 150); analogWrite(ENB, 150);
  digitalWrite(IN1, HIGH); digitalWrite(IN2, LOW);
  digitalWrite(IN3, HIGH); digitalWrite(IN4, LOW);
}

void turnLeft() {
  analogWrite(ENA, 120); analogWrite(ENB, 150);
  digitalWrite(IN1, LOW); digitalWrite(IN2, HIGH);
  digitalWrite(IN3, HIGH); digitalWrite(IN4, LOW);
}

void turnRight() {
  analogWrite(ENA, 150); analogWrite(ENB, 120);
  digitalWrite(IN1, HIGH); digitalWrite(IN2, LOW);
  digitalWrite(IN3, LOW); digitalWrite(IN4, HIGH);
}

void stopMotors() {
  digitalWrite(IN1, LOW); digitalWrite(IN2, LOW);
  digitalWrite(IN3, LOW); digitalWrite(IN4, LOW);
}

Troubleshooting & Assembly Tips

  • If motors rotate in reverse, swap the motor wire pair terminals on the L298N block.
  • Adjust the sensitivity potentiometer on each TCRT5000 IR sensor using a small screwdriver until the onboard indicator LED turns ON over black tape and OFF over white paper.
