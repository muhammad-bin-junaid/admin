================================================================================
1. QUICK START
================================================================================

1.1 Change Dashboard Password
   - Open dashboard/dash.html
   - Find line ~18: const DASHBOARD_PASSWORD = 'OLD-PASSWORD-REMOVED';
   - Change 'OLD-PASSWORD-REMOVED' to your own strong password
   - Save file

1.2 Get Apps Script Token
   - Open https://script.google.com → your project
   - Run generateToken() function
   - Check Execution Log → copy 32-character token
   - Keep this safe - do NOT put in dashboard/dash.html

1.3 First Login
   - Open dashboard/dash.html in browser (or serve via npx serve)
   - Enter dashboard password
   - When prompted "Enter Apps Script secret token" - paste your token
   - Token is stored in browser localStorage (key: makers_era_dash_token)
   - Dashboard loads

3. PASSWORD ALWAYS "INCORRECT" - FIX
================================================================================

If password always shows "Incorrect password":

CAUSE 1: Typo in password
   - Check exact case: 'OLD-PASSWORD-REMOVED' vs 'OLD-PASSWORD-REMOVED'
   - No extra spaces

CAUSE 2: Browser cache / old file
   - Hard refresh: Ctrl+Shift+R
   - Or serve fresh: npx serve . -p 3000

CAUSE 3: Script error before password check
   - Open DevTools Console (F12)
   - Look for red errors
   - Common: "Cannot read property of null" = element not found

CAUSE 4: Form not submitting
   - Check form has id="authForm"
   - Check input has id="dashPassword"

DEBUG: Add this temporarily in dashboard/dash.html script section:
   console.log('Password entered:', document.getElementById('dashPassword').value);
   console.log('Expected:', DASHBOARD_PASSWORD);

4. DASHBOARD FEATURES
================================================================================

STATS CARDS (auto-loaded):
   - Total Orders
   - Paid Orders
   - Revenue (Paid only)
   - Profit (Paid only)
   - Pending Payment
   - Shipped

ORDERS TABLE:
   - 20 per page, paginated
   - Columns: Expand | Order# | Customer | Items | Total | Order Status | Payment Status | Confirm Status | Actions
   - Search: by name, order ID, phone, email
   - Filters: Order Status, Payment Status, Confirm Status dropdowns

EXPAND ROW (click ▼):
   - Full details: date, email, campus, dept/roll, subtotal, delivery, total, cost, profit
   - Items as tags
   - Notes
   - Inline cost edit + profit preview

ACTION BUTTONS (per row):
   - Initial: Opens WhatsApp with payment request message
   - Paid: Opens WhatsApp with thank you message
   - Confirmed: Opens WhatsApp with review request
   - Edit Cost: Modal to change cost price → recalculates profit

STATUS DROPDOWNS (validated):
   - Order Status: New, Processing, Shipped, Delivered, Cancelled
   - Payment Status: Pending, Paid, Failed
   - Confirm Status: Pending, Confirmed, Rejected
   - Changes saved via Apps Script API → updates Google Sheet

COST EDIT:
   - Modal or inline → calls Apps Script updateCost
   - Profit = Total - Cost (recalculated server-side)
   - Stats refresh automatically

REFRESH: Button to reload orders + stats

9. TROUBLESHOOTING
================================================================================

"Failed to load orders"
   - Check token in localStorage: localStorage.getItem('makers_era_dash_token')
   - Clear token: localStorage.removeItem('makers_era_dash_token') → relogin
   - Check Apps Script URL in dashboard/dash.html matches deployed URL
   - Check Apps Script execution logs for errors

"Update failed"
   - Check token still valid
   - Check orderId exists in Sheet
   - Status value must match exactly: 'New', 'Processing', etc.

"WhatsApp button does nothing"
   - Check popup blocker
   - URL format: https://wa.me/923373786628?text=...

"Cost edit not saving"
   - Check cost is number >= 0
   - Check orderId correct
   - Apps Script logs for updateCost errors
